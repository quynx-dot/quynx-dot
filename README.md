## 💡 Featured Projects

### [IdeaVault — Distributed AI Clarity OS](https://github.com/janhavi-ghanghav/IdeaVault)
*Polyglot monorepo system built with Node.js/Fastify, Python/FastAPI, PostgreSQL, Redis, BullMQ, and pgvector.*
* Decoupled blocking AI enrichment workflows via **BullMQ** worker queues, cutting POST latency from **3–4 s → ~80 ms**.
* Implemented fault-tolerant background processing with exponential backoff retries, idempotent consumers, and Dead Letter Queues.
* Integrated **pgvector** for cosine similarity search and instrumented distributed tracing with **OpenTelemetry**.

### [OrderSync — Food Delivery Microservices Platform](https://github.com/janhavi-ghanghav/OrderSync)
*Distributed delivery platform across 6 isolated Node.js/TypeScript microservices.*
* Designed asynchronous message routing and decoupled inter-service communication with **RabbitMQ**.
* Built real-time rider tracking with **Socket.IO** and MongoDB 2dsphere geospatial indexing.
